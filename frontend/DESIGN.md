# Plutus — Design Spec

Источник правды по цветам: `frontend/app/globals.css` (CSS-переменные) и `tailwind.config.ts`.
Этот файл описывает правила. Если правило нарушено в коде, исправляется код, а не правило.

## 1. Принципы
- Тёмная тема основная, светлая должна быть не хуже.
- Один брендовый акцент: лайм (dark) / зелёный (light). Других брендовых цветов нет.
- Деньги читаются мгновенно: крупные суммы, единый формат, цвет только по смыслу.
- Всё, что видит пользователь, локализовано (ru/en), включая названия категорий.
- Никаких теней и градиентов ради украшения. Разделение через border и фон.

## 2. Цвета

Использовать только токены Tailwind (`bg-card`, `text-muted-foreground`, `text-income` и т.д.). Хардкод hex/hsl в компонентах запрещён.

### Существующие токены
| Токен | Dark | Light |
|---|---|---|
| background | hsl(150 11% 3.3%) | hsl(90 14% 96%) |
| card | hsl(120 6% 7%) | #ffffff |
| border | hsl(144 6% 16%) | hsl(240 6% 90%) |
| foreground | hsl(100 14% 96%) | hsl(240 10% 4%) |
| muted-foreground | hsl(140 5% 70%) | hsl(240 4% 46%) |
| primary | hsl(79 83% 65%) | hsl(142 76% 36%) |
| ring | = primary | = primary |

### Токены, которые нужно ДОБАВИТЬ в globals.css
Значения предложены с расчётом на контраст ≥ 4.5:1 на `card`. Проверить после добавления.

| Токен | Dark | Light | Назначение |
|---|---|---|---|
| income | hsl(142 70% 55%) | hsl(142 76% 30%) | доходы, рост |
| expense | hsl(0 84% 68%) | hsl(0 72% 45%) | расходы, падение |
| warning | hsl(43 96% 56%) | hsl(35 92% 38%) | лимит 80–100% |
| chart-1 | hsl(79 83% 65%) | hsl(142 76% 36%) | основная серия |
| chart-2 | hsl(79 35% 45%) | hsl(142 30% 45%) | вторая серия |
| chart-3 | hsl(150 8% 62%) | hsl(150 8% 45%) | нейтральная |
| chart-4 | hsl(43 80% 58%) | hsl(35 80% 42%) | акцентная |
| chart-5 | hsl(140 5% 40%) | hsl(140 5% 65%) | фон/прочее |

Существующий `--destructive` в dark (`0 62.8% 30.6%`) слишком тёмный для текста и иконок на чёрном. Для сумм и иконок расходов использовать `expense`, а `destructive` оставить только для фона кнопок удаления.

Запрещено в графиках и донатах: голубой, фиолетовый, розовый вне палитры `chart-*`.

## 3. Типографика

Шкала фиксированная, других размеров нет.

| Роль | Размер | Вес |
|---|---|---|
| Подписи, даты, легенды | 12px (минимум) | 400–500 |
| Основной текст, строки списков | 14px | 400–500 |
| Заголовок карточки | 16px | 600 |
| Заголовок страницы | 20–24px | 700 |
| Главная сумма капитала | 32–40px | 700 |

- Все суммы: `tabular-nums`.
- Текст меньше 12px запрещён.
- Серый вторичный текст только `text-muted-foreground`, прозрачность ниже 60% не использовать.

## 4. Spacing и формы
- Базовый шаг 4px. Padding карточки 20–24px. Gap между карточками 16–24px.
- Радиус: карточка 16px (`--radius`), кнопки и инпуты 12px, чипы и бейджи полный.
- Контент занимает ширину экрана до `max-w-[1440px]`, на широких экранах не сжимается в узкую колонку.
- Колонки сетки в одном ряду выравниваются по высоте (`items-stretch`), пустых провалов под карточкой быть не должно.

## 5. Деньги

Единый форматтер: `formatMoney(amount, currency, locale)` в `lib/utils.ts`. Другие способы форматирования сумм в компонентах запрещены.

- Знак перед символом валюты: `−$4 000,00`, `+$1,00`. Никогда `$-17`.
- Разделители по локали: ru — пробел и запятая, en — запятая и точка.
- Сокращения (`$10,8 тыс.`) только в центре доната и на осях графиков.
- Доход: `+`, цвет `income`. Расход: `−`, цвет `expense`. Перевод: нейтральный цвет, без знака.
- Сумма в иной валюте показывает конвертацию мелким текстом под основной, в формате основной валюты.

## 6. Состояния лимита
| Использовано | Цвет | Подпись |
|---|---|---|
| < 80% | primary | «$X из $Y» |
| 80–100% | warning | «Осталось $X» |
| > 100% | expense | «Превышено на $X» |

Полоса прогресса не показывает «100%» при перерасходе: выводить реальный процент (например 112%), полоса заполнена полностью.

## 7. Компоненты

### Карточка
`bg-card border rounded-2xl p-5`. Заголовок 16px/600 слева, ссылка «Смотреть все» справа 12px muted. Тени нет.

### Строка операции
Иконка в круге 32px, название 14px, дата 12px muted, сумма справа по правилам раздела 5. Название категории переводится через i18n.

### Донат расходов
- Сумма в центре помещается во внутренний диаметр кольца, иначе уменьшить шрифт или сократить формат.
- Легенда справа, проценты в сумме дают 100%, сегменты соответствуют процентам.
- Цвета только `chart-1..5`.

### График капитала
- Одна линия акцентного цвета, заливка под линией с прозрачностью до 20%.
- Цвет линии по финансовому статусу (`lib/financial-health.ts`): красный `expense`, жёлтый `warning`, зелёный `income`.
- Подписи осей 12px, не накладываются друг на друга.

### Обязательные состояния
Для каждой карточки с данными реализованы loading (skeleton), empty (текст и действие), error (сообщение и повтор).

## 8. Локализация
- Все строки через `t()`, ключи в `locales/ru/translation.json` и `locales/en/translation.json`, наборы ключей идентичны.
- Названия категорий, типов счетов и статусов переводятся. Пользовательские категории выводятся как введены.
- На одном экране не смешиваются языки интерфейса.
- Даты через `date-fns` с локалью `ru` / `en`.

## 9. Accessibility
- Контраст текста ≥ 4.5:1, иконок и границ ≥ 3:1, в обеих темах.
- Видимый `focus-visible` с `--ring` на всех интерактивных элементах.
- Tap target ≥ 44×44px на мобильном.
- Цвет не единственный носитель смысла: всегда знак `+/−` или текст статуса.
- Иконки-кнопки имеют `aria-label`. Графики имеют текстовую альтернативу (краткое описание).
- Модалки: фокус внутри, закрытие по Esc, возврат фокуса.

## 10. Запреты
- Хардкод цветов, размеров шрифта и отступов вне шкал и токенов.
- Новые цвета без добавления токена в этот файл и в `globals.css`.
- Смешение языков на экране.
- Собственное форматирование денег вне `formatMoney`.
- Утилиты `.premium-gradient`, `.glass`, `.glass-card`, `.premium-shadow`, `.text-glow` в новом коде (дубликаты или несоответствуют палитре). Использовать `bg-card border`.
- Изменение `frontend/public/new-operation-prototype.html`: интеграция только в обёртке.

## 11. Эталонные компоненты
- Карточка с главным показателем: `components/dashboard/net-worth-header.tsx`
- Список операций: `components/dashboard/recent-transactions.tsx`
- Донат: `components/dashboard/expenses-donut.tsx`
- Лимиты: `components/dashboard/limits-summary.tsx`

Перед правкой интерфейса прочитать эталон ближайшего по типу компонента и повторить его паттерны.

## 12. Чеклист проверки (для designer)
1. Нет смеси языков на экране (ru и en).
2. Все суммы через единый формат, знак перед символом.
3. Нет текста меньше 12px.
4. Контраст ≥ 4.5:1 у текста и сумм в обеих темах.
5. Цвета только из токенов, донат и графики только `chart-*`.
6. Лимит > 100% отображается как превышение.
7. Нет обрезания текста, центр доната не переполнен, колонки выровнены.
8. Есть loading/empty/error состояния.
9. Focus-ring виден, keyboard-навигация проходит по всему сценарию.
10. Mobile (375px): нет горизонтального скролла, tap target ≥ 44px.
11. Знак «+» только у дельт (доход, PnL, рост). Абсолютные суммы (стоимость, баланс, всего) без знака.
12. Подписи осей и сумм не переносятся и не обрезаются. На осях сокращённый формат.
13. Заголовок страницы везде одинаков: H1 + подзаголовок, без карточки-обёртки; действия справа.
14. Колонки в одной сетке одной высоты, пустых провалов нет.
15. Нативные date/time пикеры запрещены, только компонент проекта с локалью из i18n.
16. Все поля выбора используют один компонент и одну иконку-шеврон.
17. Иконка категории зависит от категории, одинаковых иконок у разных категорий нет.
18. Префиксы и суффиксы в полях не перекрывают значение.
19. Иконки-кнопки в модалках ≥ 44×44 зоны касания.
20. Сравнение с Overview: отступы, радиус, размеры шрифтов, плотность одинаковы.
